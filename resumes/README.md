# Resume files go here

Drop your PDFs into this folder using **exactly** these filenames (the site links to them directly):

| Role selected on the site      | Expected filename              |
|---------------------------------|---------------------------------|
| Marketing                       | `resume-marketing.pdf`          |
| Sales Support / Sales Enablement| `resume-sales-support.pdf`      |
| Events Management               | `resume-events.pdf`             |

## How to add/replace a resume (no code needed)

1. Go to your repo on github.com.
2. Open the `resumes` folder.
3. Click **Add file → Upload files**.
4. Drag in your PDF — if you're replacing an existing one, keep the **same filename** and GitHub will offer to overwrite it.
5. Click **Commit changes**.
6. GitHub Pages redeploys automatically in ~30–60 seconds — the new file is live at the same download link, no other changes needed.
